# Security policy

RowAttest is a product of RW Digital Ventures LLC.

To report a security problem in RowAttest (rowattest.com, app.rowattest.com, the REST API, or the MCP server), use GitHub's private vulnerability reporting on this repository, or email info@rowattest.com. Please do not open a public issue for a security report.

Every report is read by the founder and receives a reply confirming receipt.

RowAttest tests only the Supabase projects their owners connect to it. Testing RowAttest's own systems without written permission is not authorized.
